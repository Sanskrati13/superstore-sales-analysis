# superstore-sales-analysis
End-to-end sales data analysis using python, SQL, Power BI.
Superstore Sales Analysis

Project Overview

This project presents an end-to-end analysis of a Superstore sales dataset using Python, SQL Server, and Power BI.

The objective was to explore sales performance, identify patterns across product categories, customer segments, geographical regions, and time periods, and present the findings through an interactive dashboard.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL Server
- Power BI
- Jupyter Notebook

Project Workflow

1. Data Cleaning and Preparation

Used Python and Pandas to inspect the dataset, check missing values and duplicates, verify data types, and prepare the data for analysis.

2. Exploratory Data Analysis

Explored sales performance across categories, sub-categories, customer segments, regions, and time periods using Python.

3. SQL Analysis

Used SQL queries to calculate sales metrics, count unique orders and customers, and compare sales across different business dimensions.

4. Power BI Dashboard

Developed an interactive dashboard containing key performance indicators, sales visualizations, and filters for exploring the dataset.

Key Analysis Areas

- Overall sales performance
- Category and sub-category analysis
- Regional and state-wise sales
- Customer segment analysis
- Monthly and yearly sales trends
- Shipping method analysis

Key Findings

- Highest-performing category: Technology
- Highest-performing sub-category: Phones
- Highest-performing region: West
- Highest-performing customer segment: Consumer
- Total sales: 22,61,537 INR

Conclusion

This project demonstrates an end-to-end data analytics workflow, from data cleaning and exploratory analysis to SQL-based analysis, dashboard development, and business recommendations.
